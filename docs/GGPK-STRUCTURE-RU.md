# Диагностика GGPK без Bundles2/_.index.bin

При выборе файла `Content.ggpk` программа проверяет структуру GGPK и пытается найти `Bundles2/_.index.bin`. **Steam при этой проверке не требуется**: такое расположение индекса возможно и в отдельном клиенте GGG. Для существующего движка патчей нужен именно валидный индекс Bundles2.

Если отсутствует `Bundles2` или `_.index.bin`, приложение **не изменяет архив** и показывает до 24 элементов корня и папки Bundles2, а также несколько похожих индексных путей как **непроверенные кандидаты**. Это не доказывает, что клиент устарел либо архив повреждён. Принудительный поиск другого файла для патчинга не допускается: без подтверждения формата может быть нарушена целостность установки.

## Как собрать отчёт без изменения GGPK

В каталоге опубликованного приложения запустите:

```powershell
.\PoeAdaptive.Diagnostics.exe --inspect-ggpk "D:\Games\Path of Exile\Content.ggpk" "$env:USERPROFILE\Desktop\ggpk-structure.json"
```

Замените путь на свой, сохраните JSON **вне каталога игры**. Утилита открывает исходный GGPK только с `FileAccess.Read`, проверяет заголовок и ограниченно перечисляет записи каталога. Полный архив, пути установки, содержимое игровых файлов и Oodle DLL в отчёт не включаются. Отчёт содержит версию контейнера, размер, элементы корня, список Bundles2 и похожие пути к индексам. Перед публикацией сверяются размер и время модификации файла; это проверка отсутствия заметного изменения, а не криптографический аудит. Для полностью независимой проверки целостности используйте официальную проверку файлов клиента.

Если `GGPK` имеет другую версию, результат будет `unsupported-version`. Для GGPK v3 без Bundles2 индексирования — `bundles2-directory-missing` или `bundles2-index-missing`. При наличии подходящего пути, но невалидном содержимом индекса обычная проверка отдельно выдаст ошибку формата.

## Что приложить для разбора

Пришлите `ggpk-structure.json` и уточните PoE 1 или PoE 2, официальный отдельный клиент GGG или региональный клиент. **Полный `Content.ggpk` присылать не требуется.** Не переименовывайте записи внутри архива вручную и не используйте патчер на неизвестном формате.

Диагностическая команда исследует расположение ресурсов. Она **не добавляет** поддержку GGPK без Bundles2, поскольку текущая реализация патчей использует `LibBundle3.Index` и требует подтверждённой структуры.
