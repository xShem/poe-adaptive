# PoE Adaptive 0.3.0 — предварительная диагностическая версия

Утилита для Path of Exile 1 и Path of Exile 2, Windows 11 x64.
Продолжение [PoeRedux](https://github.com/Gineticus/PoeRedux), C# / .NET 10 / WPF.
Поддержаны адаптеры Steam, официального отдельного клиента GGG и Epic Games Store.
Отдельный **PoeAdaptive Builder** собирает универсальное приложение без Visual Studio
и прав администратора. .NET Runtime включён в оба готовых EXE.

**Это предварительная версия.** Перенесены 13 функций для PoE 1 и 15 для PoE 2.
Синтетические проверки не подтверждают правильность правил в актуальной игре.
Нулевой счётчик изменений блокирует применение всего плана. Black Screen экспериментален.
Программа не создаёт самостоятельно корректные правила будущих форматов.

## Быстрый запуск

1. Скачайте `PoeAdaptive-0.3.0-win-x64.zip` и распакуйте целиком.
2. Если ресурсы ранее менялись, выполните официальную проверку файлов клиента.
3. Завершите обновление и закройте игру. Нажмите «Найти игры», «Файл…» или «Каталог…».
4. Выберите установку, функции и параметры; посмотрите резерв требуемого места.
5. Нажмите «Анализ», проверьте счётчики и затем «Применить».
6. «Восстановить» возвращает точный исходный индекс либо полный исходный GGPK
   только текущей установки и версии; автоприменение выключается.

Нужна совместимая локальная **Windows x64 Oodle DLL** из своей установки.
Она не распространяется с приложением. Поиск: `oo2core*.dll` в выбранной игре,
затем `oo2core.dll` рядом с EXE. При смене DLL приложение просит перезапуск,
поскольку .NET кэширует нативные функции. Сборка и проверки Oodle не требуют.

## Диагностика несовместимых функций

После обновления выберите установку и проблемные функции, при необходимости укажите ожидаемое
и фактическое поведение, затем нажмите **«Собрать диагностику»**. Программа создаст
локальные ZIP, подготовит запрос для ChatGPT и позволит открыть файлы в Проводнике.
Передача выполняется только вручную. Извлечение не изменяет установленные ресурсы.

Данные имеют признаки происхождения: ручное подтверждение официальной проверки
отделено от собственного предварительного эталона, собственного патча и неизвестного файла.
Отсутствие старого эталона явно фиксируется; полный GGPK и bundles не включаются.
Подробно: [диагностика](docs/DIAGNOSTICS-RU.md).

## Самостоятельная сборка

Скачайте и распакуйте исходники и `PoeAdaptive-Builder-0.3.0-win-x64.zip`.
Запустите готовый `PoeAdaptive.Builder.exe`, выберите исходники и каталог результата,
нажмите «Собрать». При отсутствии SDK Builder предложит официальную загрузку
закреплённого SDK с проверкой SHA-512 в пользовательский каталог.
Выбирать магазин при сборке не требуется.

Из исходников также доступны `Build.cmd` и `Build.ps1`; параметры в документации.
Они вызывают тот же модуль сборки, что GUI и Windows CI.

```powershell
.\Build.ps1 -Source 'C:\Исходники\poe-adaptive' -Output 'D:\Мои сборки' -InstallSdk
# После подготовки SDK, NuGet и runtime packs:
.\Build.ps1 -Source 'C:\Исходники\poe-adaptive' -Output 'D:\Мои сборки' -Offline
```

Закреплён Microsoft .NET SDK **10.0.403**, стабильный выпуск 25.10.2026 из
[официального каталога Microsoft](https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json).
`global.json`, `build/sdk.json`, NuGet lock-файлы и CI согласованы.

Для разработчиков:

```powershell
dotnet build PoeRedux.slnx -c Release
dotnet run --project PoeAdaptive.Tests -c Release --no-build
```

Проверки — консольный раннер. `dotnet test` не заменяет их выполнение.
Ядро, движок и проверки работают на Linux; WPF запускается на Windows.

Выпуск: workflow **Publish tested Windows release** принимает успешный ID
**Build and test** и тег `v0.3.0`. Он проверяет коммит, версию и SHA-256,
публикует артефакты через Actions; готовые версии не перезаписывает.
